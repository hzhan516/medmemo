# MedMemo v1.1.9 Completion Release Scope

## Overview

v1.1.9 is the completion release for the v1.1 milestone. It finalizes the remaining M03 (layered long-term memory) and M07 (compliance & privacy) acceptance items, ships the first Knowledge Library / RAG MVP, and adds cross-module tests, benchmarks, and documentation updates.

## Included Work

| Task | Module | Description |
|------|--------|-------------|
| Confidence follow-up input refill | M07 | When the compliance engine asks a clarifying question, refill the clarified user input back into the chat context so the conversation can continue seamlessly. |
| Persistent answer-accuracy feedback loop | M07 | Store user feedback on answer quality, aggregate accuracy metrics, and feed them back into prompt/retrieval tuning. |
| Knowledge Library / RAG MVP | M03 | Import Markdown/JSONL documents, build a keyword index and a vector index, run hybrid search with RRF, and surface citations in generated answers. |
| Memory archive and session-gap closure (#004 / #035) | M03 | Close the two open memory issues: archive conversations into long-term memory and recall relevant memories across session gaps. |
| Cross-module tests and benchmarks | — | Add or extend tests and benchmarks that exercise the combined M03/M07 flows. |
| Documentation and changelog updates | docs | Release scope docs, changelog entries, and AGENTS.md updates if conventions change. |

## Frozen / Out of Scope

The following items remain intentionally frozen or deferred for this release:

- `FamilyRepoKuzu` — stubbed graph-database repository; no kùzǔ binding in v1.1.9.
- `DuckDBConnector` — intentionally frozen; active storage backend remains SQLCipher/SQLite.
- Sparkle integration — macOS auto-update remains browser-guided; Sparkle framework integration is deferred.
- macOS Developer ID notarization.
- Windows Authenticode signing.
- Large public medical dataset adapters (Huatuo-26M, PubMedQA, CMeKG).

## Compliance Note

MedMemo remains a hospital-triage / health-consultation information tool and is **not** a medical device. This release does not introduce definitive diagnosis, prescription, dosage, or treatment-plan recommendation capabilities. All LLM outputs continue to pass the four-level compliance interception pipeline before being displayed.
