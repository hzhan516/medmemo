# 功能地图

> 🌐 [English Version](../../../kb/Feature-Map.md)

| 模块 | 范围 |
|------|------|
| M01 Chatbox 对话引擎 | 对话编排、流式输出、标题生成、上下文压缩 |
| M02 多模型自由切换 | Provider 配置、健康检查、鉴权方式 |
| M03 分层长期记忆池 | 事实抽取、审核、语义召回、记忆注入 |
| M04 家族关系网图谱 | v2+ 规划，v1.x 中为冻结仓库存根 |
| M05 可视化记忆管理台 | 记忆列表、搜索、审核、统计 |
| M06 端云协同 | 本地 NER、本地 embedding、本地/云 Provider 路由 |
| M07 合规与隐私保护 | 脱敏、合规拦截、紧急症状流程 |
