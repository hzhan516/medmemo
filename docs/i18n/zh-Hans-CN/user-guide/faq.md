# 常见问题

> 🌐 [English Version](./../../../user-guide/faq.md)

> 关于安装、配置和使用 MedMemo 的常见问答。

---

## 安装

### Q1：MedMemo 支持哪些平台？

**答：** Windows 10+、macOS 12+ 和 Linux（Ubuntu 20.04+、Fedora 38+）。支持 x64 和 ARM64 架构。

### Q2：使用 MedMemo 需要 API Key 吗？

**答：** 除非通过 Ollama 使用本地模型，否则需要。云端提供商（Kimi、OpenAI、阿里云）需要 API Key。大多数提供商都提供免费额度。

### Q3：如何获取 Kimi API Key？

**答：** 访问 [platform.moonshot.cn](https://platform.moonshot.cn)，注册账号，在控制台创建 API Key。

### Q4：如何获取 OpenAI API Key？

**答：** 访问 [platform.openai.com](https://platform.openai.com)，注册账号，进入 **API Keys** 页面创建。

### Q5：MedMemo 可以离线使用吗？

**答：** 部分可以。初次下载和云端模型需要联网。但如果配置了本地 Ollama 模型，安装后 MedMemo 可以完全离线工作。

### Q6：macOS 首次启动为什么拦截 MedMemo？

**答：** MedMemo 是开源应用，未做 Apple 公证。前往**系统设置 → 隐私与安全性 → 仍要打开**即可允许。详见 [安装指南 → macOS](./installation.md#macos)。

### Q7：MedMemo 需要多少磁盘空间？

**答：** 约 200 MB — 应用本体约 50 MB，加上本地数据库和可选的 AI 模型。

## 配置

### Q8：如何切换 AI 模型？

**答：** 前往 **设置 → 默认模型**，点击你偏好的提供商。更改将应用于新建的会话。

### Q9：不同会话可以使用不同模型吗？

**答：** 当前版本不支持。默认模型应用于所有新建会话。该功能计划在后续版本中支持。

### Q10：我的 API Key 存储在哪里？

**答：** 存储在你的操作系统安全密钥环中 —— macOS Keychain、Windows Credential Manager 或 Linux Secret Service。绝不会以明文形式存储。

### Q11：如何更换主题？

**答：** 前往 **设置 → 外观**，选择亮色、暗色或跟随系统。更改立即生效，无需重启。

### Q12："合规提示条"是什么，应该关闭吗？

**答：** 合规提示条是蓝色信息条，提醒你 AI 输出仅供参考，不构成医疗建议。建议保持**始终展示**以提高安全意识。可在 **设置 → 合规提示条** 中更改。

## 对话与会话

### Q13：会话有长度限制吗？

**答：** 没有硬性限制，但很长的会话可能会被摘要压缩以适应 AI 模型的上下文窗口。早期消息会被压缩，同时保留关键信息。

### Q14：可以导出对话吗？

**答：** 导出功能（JSON/Markdown）计划在后续版本中支持。目前对话存储在本地加密 SQLite 数据库中。

### Q15：关闭 MedMemo 后对话会丢失吗？

**答：** 不会。对话自动保存。重新打开 MedMemo 后，你可以在侧边栏看到会话和所有消息。

### Q16：为什么 AI 回复到一半停止了？

**答：** 可能原因：
- 你点击了**停止按钮**
- 网络超时（检查网络连接）
- 触发了 AI 提供商的速率限制
- 触发了合规 L1 拦截（检测到高风险内容）

### Q17：发送消息后还能编辑吗？

**答：** 可以在输入框为空时按 `↑`（上方向键）召回上一条消息，编辑后重新发送。暂不支持历史消息的内联编辑。

### Q18：`/new` 命令有什么作用？

**答：** 在输入框中输入 `/new` 并按 `Enter` 可创建新会话。这是侧边栏按钮或 `Ctrl+N` 快捷键的快速替代方式。

## 隐私

### Q19：MedMemo 会上传我的对话到云端吗？

**答：** 不会。对话存储在本地加密数据库中。只有**脱敏后**的文本才会发送给 AI 提供商，敏感信息在发送前已被替换为占位符。

### Q20：什么是"脱敏"？

**答：** 这是一个自动过程，在发送到云端 AI 之前，将敏感个人信息（姓名、手机号、身份证号、地址）替换为 `<NAME_1>` 或 `<PHONE_1>` 等占位符。收到 AI 回复后，原始文本在本地还原。

> **重要说明：** 脱敏保护的是发往云端 AI 提供商的内容；聊天界面与本地数据始终显示原文。

### Q21：MedMemo 工作人员能读取我的对话吗？

**答：** 不能。所有数据都存储在你的本地设备上。没有远程服务器或云端存储用于存放对话。

### Q22：如何彻底删除所有数据？

**答：** 卸载 MedMemo 并删除用户数据文件夹：
- **Windows**：`%LOCALAPPDATA%\medmemo`
- **macOS**：`~/Library/Application Support/medmemo`
- **Linux**：`~/.local/share/medmemo`

### Q23：MedMemo 会收集分析数据吗？

**答：** 不会收集遥测或使用分析数据。唯一的"分析"是本地引导向导完成统计（仅存储在你的设备上），用于优化首次使用体验。

## 故障排查

### Q24：安装后应用无法启动怎么办？

**答：** 详见 [故障排查 → 安装问题](./troubleshooting.md#安装问题)。

### Q25：为什么某些 AI 回复上有橙色警告？

**答：** 合规引擎检测到潜在敏感健康内容。警告提醒你，医疗决策应咨询医生。

### Q26：看到红色紧急警报该怎么办？

**答：** 请认真对待。A 级警报表示可能存在危及生命的症状。考虑拨打急救电话或前往急诊。如果你认为是误报，也可以选择继续对话。

### Q27：AI 回复很慢，如何加速？

**答：** 尝试切换到更快的模型（Kimi Lite 或 GPT-4o Mini）。本地模型（Ollama）速度取决于你的硬件 —— GPU 能显著提升速度。
