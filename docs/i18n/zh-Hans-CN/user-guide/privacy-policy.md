# 隐私政策

> 🌐 [English Version](./../../../user-guide/privacy-policy.md)

> 本文档说明 MedMemo 如何处理你的数据。MedMemo 秉承**隐私优先、本地优先**的设计理念。

---

## 我们的承诺

**你的健康数据绝不会离开你的设备，除非你明确选择使用云端 AI 模型 —— 即便如此，敏感信息也会在发送前自动移除。**

MedMemo 不会：
- 收集使用分析或遥测数据
- 将对话存储在远程服务器上
- 与第三方分享你的数据
- 将数据用于广告或保险画像
- 跨会话追踪你的行为

---

## 我们收集的数据

### 本地存储的数据

| 数据类型 | 用途 | 存储位置 |
|---------|------|---------|
| **对话记录** | 聊天历史和消息 | 本地 SQLite 数据库（加密）|
| **会话标题** | 组织聊天线程 | 本地 SQLite 数据库（加密）|
| **设置项** | 主题、模型偏好、合规模式 | 本地 SQLite 数据库（加密）|
| **API Key** | AI 提供商身份验证 | 操作系统密钥环（macOS Keychain / Windows Credential Manager / Linux Secret Service）|
| **免责声明记录** | 接受记录及时间戳 | 本地 SQLite 数据库（加密）|
| **引导统计** | 向导完成统计（仅本地）| 本地存储 |

### 发送至云端的数据（仅使用云端模型时）

当你使用云端 AI 提供商（Kimi、OpenAI、阿里云）时：

| 发送的内容                 | 不发送的内容           |
|-----------------------|------------------|
| **脱敏后**的对话文本          | 原始姓名、手机号、身份证号、地址 |
| 模型类型和 API Key（用于身份验证） | 家族健康信息           |
|                       | 使用行为日志           |

**脱敏流程：**
```
你的输入
  → L1 规则引擎（正则模式：证件号、手机号、邮箱）
    → L2 NER 模型（姓名、地点、机构名）
      → 安全出站文本
        → 安全文本发送至云端 API
```

原始文本在收到 AI 回复后在本地还原。映射关系永远不会离开你的设备。

## 你的数据如何受到保护

### 加密

| 层级 | 方式 | 详情 |
|------|------|------|
| **数据库** | AES-256-GCM | 通过 SQLCipher 实现全数据库加密 |
| **API Key** | 操作系统密钥环 | 平台原生安全存储 |
| **加密密钥** | CSPRNG + 密钥环 | 256 位随机密钥存储在操作系统密钥环中 |

### 访问控制

- 所有数据文件存储在你的用户配置文件目录中
- 未经你的操作系统凭证，其他应用或用户无法访问 MedMemo 的数据
- MedMemo 不以管理员/root 身份运行

### 纯本地操作

以下操作完全在本地离线进行：
- 紧急症状检测
- 合规内容过滤
- 会话管理（增删改查）
- 主题切换
- 设置存储
- Markdown 渲染

## 你的权利

作为 MedMemo 用户，你对数据拥有完全控制权：

| 权利 | 如何行使 |
|------|---------|
| **访问** | 所有数据在应用中可见。数据库文件位于本地存储中。 |
| **删除** | 删除单个会话（回收站 → 30 天后永久删除）或通过卸载清除全部数据 |
| **导出** | 未来版本将支持以 JSON/Markdown 格式导出对话 |
| **限制** | 在 **设置 → 隐私 → 数据留存期限** 中设置留存期限 |
| **撤回同意** | 随时拒绝免责声明（应用将关闭）。重新打开以再次接受。 |

## 第三方服务

MedMemo 仅在**你配置后**才集成以下外部服务：

| 服务 | 发送的数据 | 隐私政策 |
|------|-----------|---------|
| Moonshot (Kimi) | 脱敏后的文本 | [moonshot.cn](https://platform.moonshot.cn) |
| OpenAI (GPT) | 脱敏后的文本 | [openai.com/privacy](https://openai.com/privacy) |
| 阿里云 (通义千问) | 脱敏后的文本 | [alibabacloud.com](https://www.alibabacloud.com) |
| GitHub Releases | 仅版本检测 | [github.com/privacy](https://github.com/privacy) |

> **Ollama（本地模型）**：不向任何地方发送数据。所有运算在你的机器上完成。

## 数据留存期限

你可以控制 MedMemo 保留数据的时长：

| 设置 | 行为 |
|------|------|
| **7 天** | 超过 7 天的对话自动删除 |
| **30 天** | 超过 30 天的对话自动删除 |
| **90 天** | 超过 90 天的对话自动删除 |
| **1 年** | 超过 1 年的对话自动删除 |
| **永久** | 数据永久保留，直到你手动删除 |

在 **设置 → 隐私 → 数据留存期限** 中更改此设置。

## 儿童隐私

MedMemo 不面向 13 岁以下儿童使用。我们不会故意收集儿童数据。
