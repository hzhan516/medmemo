## MedMemo 是什么

MedMemo 是一款**开源桌面端健康信息工具**，通过自然语言对话帮助你解答健康问题。它**不是医疗器械**，不提供诊断、治疗建议或处方。

你的所有数据都保存在本地设备上。对话内容经过本地加密，敏感信息在调用云端 API 前会自动匿名化处理。

## 首次设置（3 步）

首次打开 MedMemo 时，你将经历一段简短的引导：

1. **免责声明** — 阅读并接受医疗免责声明（必须完成才能继续使用）
2. **隐私设置** — 选择脱敏级别和数据留存期限
3. **模型配置** — 输入你偏好的 AI 提供商 API Key（Kimi、OpenAI 等）

> 💡 你可以随时从 **设置 → 安装向导 → 重新运行** 再次进入引导流程。

## 核心概念

### 会话
会话是一个独立的聊天线程。你可以创建无限数量的会话，重命名、搜索和删除它们。删除的会话会进入**回收站**，30 天后永久清除。

### 合规体系
MedMemo 内置合规引擎，监控你的输入和 AI 输出中潜在的健康风险内容。根据风险等级，你可能会看到：
- **蓝色信息条** — 每个新会话顶部的常规免责声明
- **橙色警告框** — 需要特别注意的内容
- **红色警告横幅** — 检测到紧急症状（B 级）
- **全屏红色弹窗** — 严重紧急症状（A 级）

### 脱敏处理
在将消息发送至云端 AI 提供商之前，MedMemo 会自动将敏感个人信息（姓名、手机号、身份证号）替换为占位符。原始文本绝不会通过网络发送。

### 模型
MedMemo 支持多种 AI 提供商：
- **Kimi Lite**（Moonshot）— 速度快，中文优化
- **GPT-4o Mini**（OpenAI）— 性能均衡
- **通义千问 Turbo**（阿里云）— 中文优化
- **Llama 3.1 8B**（本地 Ollama）— 完全在本地运行

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 发送消息 |
| `Shift + Enter` | 插入换行 |
| `Escape` | 清空输入 |
| `↑`（输入框为空时）| 编辑上一条用户消息 |
| `Ctrl / Cmd + N` | 新建会话 |
| `/new` | 新建会话（在输入框中输入）|
| `Ctrl + /` | 聚焦输入框 |

完整快捷键列表见 [快速入门 → 键盘快捷键](./getting-started.md#键盘快捷键)。
