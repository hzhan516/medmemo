> 🌐 [English Version](./../../../../user-guide/getting-started.md)

## 主界面布局

MedMemo 采用分栏式布局：

```
┌─────────────────┬────────────────────────────────────┐
│                 │  标题栏（标题 + 设置 + 主题切换）      │
│   侧边栏         ├────────────────────────────────────┤
│  （会话列表，    │  合规提示条（蓝色信息条）              │
│   可搜索）       ├────────────────────────────────────┤
│                 │                                    │
│   200-400px     │           聊天消息区域               │
│   （可拖拽调整）  │           （可滚动）                 │
│                 │                                    │
│                 │                                    │
│                 ├────────────────────────────────────┤
│                 │  输入框 + 发送按钮                   │
│                 │  （下方显示快捷键提示）                │
└─────────────────┴────────────────────────────────────┘
```

- **侧边栏**（左侧）：会话列表、搜索、回收站
- **标题栏**（顶部）：应用标题、主题切换、设置入口
- **合规提示条**：蓝色信息条，提醒 AI 输出仅供参考
- **聊天区域**：消息气泡 — 蓝色为你，白色/灰色为 AI
- **输入框**（底部）：在此输入问题

## 开始对话

### 方式 1：新建会话按钮
点击侧边栏顶部的 **"新建对话"**（或按 `Ctrl/Cmd + N`）。

### 方式 2：斜杠命令
在输入框中输入 `/new` 并按 `Enter`。

### 方式 3：空状态
没有会话时，聊天区域显示欢迎界面，点击 **"开始对话"** 按钮。

## 发送消息

1. 点击底部输入框（或按 `Ctrl + /` 聚焦）
2. 输入你的健康问题
3. 按 `Enter` 发送

> 💡 **提示**：MedMemo 支持多行消息。按 `Shift + Enter` 插入换行而不发送。

### AI 回复过程中

- 发送按钮变为**停止按钮**（方块图标）。点击它或按 `Enter` 停止生成。
- 文字逐字出现（流式输出），带来自然的阅读体验。
- 如果回复被中断，消息会标注 **"[用户中断]"**，但已生成的内容会保留。

### 编辑上一条消息

如果输入框为空，按 `↑`（上方向键）可将上一条发送的消息填充到输入框中。编辑后重新发送。

## 会话管理

### 侧边栏功能

| 功能 | 操作方式 |
|------|---------|
| **搜索** | 在会话列表上方的搜索框中输入关键词 |
| **重命名** | 右键会话 → **重命名**（最多 16 个字符）|
| **删除** | 右键会话 → **删除**（移至回收站）|
| **撤销删除** | 删除后 5 秒内出现提示条 — 点击**撤销** |
| **回收站** | 点击侧边栏底部的**回收站**图标查看已删除会话 |
| **调整宽度** | 拖拽侧边栏和聊天区域之间的分隔线（200–400px）|
| **收起** | 点击收起箭头（窗口宽度 < 768px 时自动收起）|

### 时间分组

会话按时间自动分组：
- **置顶**（如有）
- **今天**
- **昨天**
- **近 7 天**
- **更早**

## 设置

点击标题栏中的**齿轮图标**打开设置。

### 外观

| 主题 | 说明 |
|------|------|
| **亮色** | 明亮背景，深色文字 |
| **暗色** | 深色背景，浅色文字 |
| **跟随系统** | 自动跟随操作系统主题 |

### 默认模型

选择你偏好的 AI 提供商：

| 模型 | 提供商 | 位置 |
|------|--------|------|
| Kimi Lite | Moonshot | 云端 |
| GPT-4o Mini | OpenAI | 云端 |
| 通义千问 Turbo | 阿里云 | 云端 |
| Llama 3.1 8B | Ollama | **你的机器** |

> **本地模型**（Ollama）需要你单独安装并运行 Ollama。无需 API Key，数据不会离开你的设备。

### 合规提示条模式

| 模式 | 行为 |
|------|------|
| **始终展示** | 每个新会话都显示蓝色信息条（当前会话可手动关闭）|
| **首次展示** | 每个会话仅首次进入时展示，关闭后不再显示 |
| **关闭** | 永不显示 |

> ⚠️ 建议保持**始终展示**，以提高安全意识。

### 隐私设置

**脱敏级别：**
- **标准** — 规则匹配 + NER 模型（均衡方案）
- **严格** — 三重防护（最大程度保护隐私）
- **关闭** — 不脱敏（不推荐）

**数据留存期限：**
- 选项：7 天 / 30 天 / 90 天 / 1 年 / 永久
- 超过期限的数据将自动清理

### 自动更新

- 开启/关闭自动更新检测
- 选择通道：**稳定版** 或 **测试版**

## 键盘快捷键

### 输入框

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 发送消息 |
| `Shift + Enter` | 插入换行 |

| `Ctrl + /` | 聚焦输入框 |

### 全局

| 快捷键 | 功能 |
|--------|------|
| `Ctrl / Cmd + N` | 新建会话 |

### 侧边栏

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 确认重命名 |
| `Escape` | 取消重命名 |

## 理解 AI 回复

MedMemo 的 AI 回复可能包含特殊视觉标识：

| 标识 | 含义 |
|------|------|
| 顶部**蓝色信息条** | 常规免责声明 — "AI 输出仅供参考" |
| **橙色警告框** | 合规引擎标记的内容 — 请仔细阅读 |
| **红色警告横幅** | 检测到紧急症状（B 级）— 确认后才能继续 |
| **全屏红色弹窗** | 严重紧急情况（A 级）— 考虑拨打急救电话 |

> 🚨 **如果看到 A 级紧急警报**，请认真对待。警报提供拨打急救电话、查找附近急诊或继续咨询的选项。

## Markdown 支持

AI 回复支持丰富的格式：

- **粗体**、*斜体*、`行内代码`
- 带语法高亮的代码块
- 表格
- 项目符号和编号列表
- 可点击链接

医学术语可能显示**虚线下划线** — 悬停查看工具提示定义。

## 最佳实践

1. **具体描述** — 与其说"我不舒服"，不如描述症状、持续时间和严重程度
2. **每会话一个主题** — 保持上下文聚焦，回复更精准
3. **关注合规提示** — 它们是为了确保信息安全准确
4. **绝不忽略 A 级警报** — 它们检测可能危及生命的症状
5. **向医生核实** — MedMemo 提供信息，不提供医疗建议
