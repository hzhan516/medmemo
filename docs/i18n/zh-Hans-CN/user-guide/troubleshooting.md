## 安装问题

### 应用无法启动（Windows）

**现象：** 双击安装程序或应用无反应，或弹出错误对话框。

**解决方案：**
1. 确认 Windows 版本为 10 或更高（`Win + R`，输入 `winver`）
2. 尝试以普通用户身份运行（非管理员）
3. 若 SmartScreen 拦截：点击**更多信息 → 仍要运行**
4. 检查 Windows Defender 排除项 — 如被误报，添加 MedMemo 为例外
5. 从 GitHub Releases 重新下载安装程序（文件可能损坏）

### 应用无法启动（macOS）

**现象：** 提示 "MedMemo 无法打开，因为无法验证开发者"。

**解决方案：**
1. 打开**系统设置 → 隐私与安全性**
2. 向下滚动并点击**仍要打开**
3. 若无效，在终端运行：
   ```bash
   xattr -d com.apple.quarantine /Applications/MedMemo.app
   ```
4. 确保 macOS 版本为 12 (Monterey) 或更高

### 应用无法启动（Linux）

**现象：** AppImage 无法启动，或显示库错误。

**解决方案：**
1. 确保有执行权限：`chmod +x MedMemo.AppImage`
2. 安装缺失依赖：
   - Ubuntu/Debian：`sudo apt install libwebkit2gtk-4.1-0`
   - Fedora：`sudo dnf install webkit2gtk4.1`
3. 若使用 Wayland，尝试：`./MedMemo.AppImage --enable-features=UseOzonePlatform --ozone-platform=wayland`
4. 检查 AppImage 与你的发行版版本兼容性

## AI 模型问题

### "发送消息失败" 错误

**现象：** 发送消息时出现红色错误条。

**解决方案：**
1. 检查网络连接
2. 在**设置**中确认 API Key 正确（如不确定请重新输入）
3. 查看 AI 提供商状态页面（如 [OpenAI Status](https://status.openai.com)）
4. 尝试在 **设置 → 默认模型** 中切换到其他模型
5. 若使用 Ollama，确保服务正在运行：`ollama serve`

### AI 回复非常慢

**现象：** 第一个字出现前延迟很长，或流式输出卡顿。

**解决方案：**
1. 切换到更快的模型（Kimi Lite 通常对中文最快）
2. 检查网络速度（云端模型需要稳定网络）
3. 若使用本地 Ollama：
   - 确保机器有足够内存（建议 8GB+）
   - GPU 能显著提升本地推理速度
   - 尝试更小的模型（如 Llama 3.1 8B 替代 70B）
4. 关闭其他占用资源的应用

### "模型不可用" 错误

**现象：** 提示所选模型不可用。

**解决方案：**
1. 云端模型：检查 API Key 和网络连接
2. Ollama：确认模型已下载（`ollama list`）且服务正在运行
3. 检查提供商是否已弃用该模型（查看其官方文档）

## 隐私与安全问题

### 脱敏似乎没有生效

**现象：** 怀疑敏感信息未被替换就发送了。

**如何验证：**
1. 检查 **设置 → 隐私 → 脱敏级别** — 确保未设为"关闭"
2. 脱敏过程是自动静默进行的
3. 确认是否生效：发送包含假手机号如 `13800138000` 的消息 — 如果 AI 回复引用了你的输入，不应包含该号码

### 忘记数据存储位置

**存储位置：**
- **Windows**：`%LOCALAPPDATA%\medmemo\`
- **macOS**：`~/Library/Application Support/medmemo/`
- **Linux**：`~/.local/share/medmemo/`

> ⚠️ 这些文件夹包含加密数据。请勿手动编辑。

## 界面问题

### 侧边栏消失了

**现象：** 看不到会话列表。

**解决方案：**
1. 若窗口较窄（< 768px），侧边栏会自动折叠为图标。点击**面板图标**展开。
2. 若完全收起，点击折叠侧边栏左上角的**展开箭头**。
3. 将窗口拉宽以恢复完整侧边栏。

### 暗色模式显示异常

**现象：** 暗色模式下某些 UI 元素显示不正确。

**解决方案：**
1. 在 **设置 → 外观** 中切换主题后再切换回来
2. 重启 MedMemo
3. 若 Linux 使用自定义主题，MedMemo 可能意外继承系统颜色

### 文字太小 / 太大

**现象：** 聊天文字难以阅读。

**解决方案：**
1. 使用操作系统级别的缩放（MedMemo 尊重系统显示缩放设置）
2. 调整窗口大小 — 聊天区域会自动适应
3. 后续版本将支持应用内字体大小调节

## 性能问题

### 内存占用过高

**现象：** MedMemo 占用 500MB+ 内存。

**预期占用：**
- 基础应用：~100-200 MB
- 加载 ONNX 模型后：+100-200 MB
- 长会话：逐渐增加（有清理上限）

**若占用过高：**
1. 重启 MedMemo
2. 关闭不用的会话（仍在侧边栏但释放渲染内存）
3. 若使用本地 Ollama 模型，内存占用取决于模型大小（8B ≈ 6GB，70B ≈ 40GB）

### 应用感觉卡顿

**现象：** UI 响应慢，滚动不流畅。

**解决方案：**
1. 减少可见消息数量（滚动加载更多）
2. 检查系统是否内存不足
3. 禁用不必要的浏览器扩展（MedMemo 使用 WebView）
4. Linux 上确保 WebKit 可用 GPU 加速

## 更新问题

### 更新检测失败

**现象：** 提示 "检测更新失败"。

**解决方案：**
1. 检查网络连接
2. GitHub 可能限流 — 稍后再试
3. 若处于公司代理后，配置系统代理设置
4. 你也可以随时从 GitHub 手动下载最新版本

### 更新下载中断

**现象：** 下载到一半停止，无法恢复。

**解决方案：**
1. 下次启动时会自动重试更新
2. 或从 GitHub Releases 手动下载并重新安装
