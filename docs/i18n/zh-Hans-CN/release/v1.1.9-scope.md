# MedMemo v1.1.9 完成版发布范围

## 概述

v1.1.9 是 v1.1 里程碑的完成版发布。它收尾 M03（分层长期记忆池）和 M07（合规与隐私保护）剩余的验收项，交付首个知识库 / RAG MVP，并补充跨模块测试、基准测试与文档更新。

## 包含工作

| 任务 | 模块 | 说明 |
|------|------|------|
| 置信度追问输入回填 | M07 | 当合规引擎发起澄清追问时，将澄清后的用户输入回填到聊天上下文，保证对话连续。 |
| 回答准确率持久化反馈 | M07 | 存储用户对回答质量的反馈，聚合准确率指标，并反馈到提示词/检索调优。 |
| 知识库 / RAG MVP | M03 | 导入 Markdown/JSONL 文档，构建关键词索引与向量索引，使用 RRF 进行混合搜索，并在生成回答中给出引用。 |
| 记忆归档与会话间隙补全（#004 / #035） | M03 | 关闭两个待办记忆项：将对话归档为长期记忆，并在会话间隙召回相关记忆。 |
| 跨模块测试与基准测试 | — | 新增或扩展覆盖 M03/M07 组合流程的测试与基准测试。 |
| 文档与更新日志 | docs | 发布范围文档、更新日志条目，以及如有变化的 AGENTS.md 更新。 |

## 冻结 / 不包含范围

以下项目在本版本中仍被有意冻结或推迟：

- `FamilyRepoKuzu` — 已 stub 的图数据库仓库；v1.1.9 不接入 kùzǔ 绑定。
- `DuckDBConnector` — 有意冻结；当前活跃存储后端仍为 SQLCipher/SQLite。
- Sparkle 集成 — macOS 自动更新保持浏览器引导下载；Sparkle 框架集成推迟。
- macOS Developer ID 公证。
- Windows Authenticode 签名。
- 大型公开医学数据集适配器（Huatuo-26M、PubMedQA、CMeKG）。

## 合规说明

MedMemo 仍定位为医院分诊 / 健康咨询信息工具，**不是**医疗器械。本版本不引入确诊、开药、剂量或治疗方案推荐能力。所有 LLM 输出在展示前仍需通过四级合规拦截管道。
