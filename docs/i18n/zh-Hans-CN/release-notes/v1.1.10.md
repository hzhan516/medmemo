# MedMemo v1.1.10 发布说明

> English version see [`docs/release-notes/v1.1.10.md`](../../../release-notes/v1.1.10.md).

## 概述

MedMemo v1.1.10 是一次发布加固更新，重点提升正式版发布链路、校验和机制与升级路径的健壮性与可审计性。本次更新不包含新的诊断或治疗功能。

**重要提示：** MedMemo 是一款个人健康信息助手，**不是医疗器械**，**不提供诊断**、**不开具处方**、**不推荐治疗方案**。请务必遵循专业医疗人员的建议。

## 主要改进

- **发布链路加固**：正式版现在采用 Draft 两阶段发布，必须在 `production-release` Environment 经人工审批后才能公开。
- **校验和 fail-closed**：所有安装包统一记录在六文件 manifest 中；更新下载前必须校验 checksum，安装时再次校验，任何不符都会删除临时文件并提示稍后重试。
- **Windows 数据目录**：升级用户优先使用旧数据目录；安装目录不可写时自动回退到 `%USERPROFILE%\.medmemo\data`。
- **macOS 与 Linux 数据目录**：为保持兼容，默认仍使用 `~/.medmemo/data`；可通过 `MEDMEMO_DATA_DIR` 或 `config.yaml` 覆盖。
- **Linux 包更新**：自动探测 DEB/RPM 安装方式，以便 updater 选择正确的更新包；AppImage 仍作为便携默认方案。
- **证据工作流**：五平台测试证据通过 `record-release-test.yml` 记录，并由 `finalize-release.yml` 在公开前统一校验。

## Windows

### 旧数据目录优先

当旧数据目录与新安装目录数据文件夹同时存在时，MedMemo 优先使用旧位置，确保升级后历史记录仍然可见。如果你在使用某个 release candidate 期间将数据存入了新的安装目录位置，请通过 `MEDMEMO_DATA_DIR` 或 `config.yaml` 显式指向该文件夹。

### 安装目录不可写时回退

在全新安装或升级时，如果安装目录（例如 `C:\Program Files\MedMemo`）不可写，MedMemo 会自动回退到 `%USERPROFILE%\.medmemo\data`。不会执行任何自动迁移、删除或合并数据库的操作。

## Linux

### 从 rc DEB/RPM 升级

如果你通过 DEB 或 RPM 包安装了 v1.1.10 的某个 release candidate，需要手工覆盖安装一次最终的 DEB/RPM 包。此后 updater 会根据已探测到的包类型自动选择正确的更新包。

### AppImage

AppImage 为便携版本，原地更新。运行前请确保文件具有可执行权限（`chmod +x`）。

## 校验和验证

所有发布资产均列在 `scripts/build/release-assets-manifest.json` 中。更新时：

1. 若预期 checksum 为空，updater 拒绝下载。
2. 下载完成后立即校验 checksum；不匹配则删除临时文件并提示稍后重试。

你也可以手动验证：

```bash
sha256sum -c checksums.txt
```

## 已知限制

- macOS ARM 产物在 CI 中构建并检查；无实机验证是已登记的残余风险。
- 本版本不包含 Linux arm64 的 DEB/RPM 包。
- 当校验和不可用时 updater 不会执行下载，但 UI 仍会显示新版本可用。

## MedMemo 不会做什么

MedMemo 旨在帮助你整理和回顾健康相关信息，它**不会**：

- 给出确定性诊断；
- 推荐具体药物、剂量或化验项目；
- 制定治疗计划或建议手术。

如遇紧急医疗情况，请拨打当地急救电话或前往最近的急诊室。
