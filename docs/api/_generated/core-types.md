DesensitizationLevel 表示数据脱敏处理强度级别。 该级别仅标记用户偏好，实际脱敏流水线的分级执行策略由 usecase 层根据此配置动态调整。

- **Type**: `string`

| Constant | Value | Description |
|----------|-------|-------------|
| `DesensitizationStandard` | "standard" | DesensitizationStandard 标准级：启用 L1 规则脱敏 + L2 NER 模型脱敏。 |
| `DesensitizationStrict` | "strict" | DesensitizationStrict 严格级：在 standard 基础上追加兜底策略（待产品/合规确认后细化）。 |
| `DesensitizationOff` | "off" | DesensitizationOff 关闭级：跳过出网脱敏。仅应在用户明确知情并承担风险时使用。 |
